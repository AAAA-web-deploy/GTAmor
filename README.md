# Grand Theft Amor — redesigned website

This folder contains a static website and all its assets. Upload the contents of this folder (index.html, styles.css, site.js, and assets/) to the root of a static host. For a local preview run `python3 -m http.server 8000`, then open http://localhost:8000.

The desktop layout intentionally uses the approved flattened mockup as a full-page image so its custom typography, boundaries, composition and colors match the approved design precisely. The navigation hotspots and gallery buttons are functional, and a screen-reader description is included. After a gallery control is used, the images change to separate gallery assets. The first render preserves the exact mockup appearance.

The mobile version is a responsive interpretation assembled from individual images and live HTML text; it is not a pixel-exact rendering of the desktop picture. The desktop picture's text, imagery and content are baked in: altering those visible elements requires editing/replacing the artwork or rebuilding that section in HTML. A high-resolution monitor may reveal scaling of the 1024×1536 design. All typography text in the mobile version remains editable in index.html.

Six gallery images are included: the original dock, original home and original couch scenes, plus the new dock, reunion and couch. Arrow buttons and touch swipes cycle through all six. The user-provided project has not supplied supply, network, contract address, purchase URL or social URLs; these are placeholders and no active links are fabricated.

The images are AI-generated fan interpretations, not actual Rockstar screenshots, and are not verified to match game characters or scenes exactly. Font license notices are in assets/fonts/. See reference/approved-mockup.png for the design reference.
