# Grand Theft Amor — asset guide

- `approved-mockup.png`: final full-page approved desktop design with typography and soft transitions baked in.
- `hero.png`: standalone recreation of the hero for mobile or future design work.
- `reunion.png`, `dock-new.png`, `quiet-new.png`: standalone scenes for the three story chapters.
- `skyline.png`: standalone skyline used for the mobile tokenomics section.
- `dock-original.png`, `home-original.png`, `couch-original.png`: previous site's gallery images, retained in the new rotating gallery.
- `token-logo.png`, `banner.png`: previously created token logo and banner.
- `palm.svg`: brand mark; `fonts/` contains the mobile fonts and their license notices.

All scene images are AI-generated fan interpretations. They are not official Rockstar images, and the exact likenesses, clothing, locations and poses have not been verified against original game frames. The approved mockup is a single flattened image and its custom title lettering does not exist as an editable font.

The matching website uses the full mockup as desktop artwork for exact visual fidelity. Because the desktop text is baked into that artwork, changing token information there requires updating the artwork or rebuilding the sections in HTML. Mobile is built with live text and the separate scene images and is a responsive interpretation, not an exact desktop replication.
